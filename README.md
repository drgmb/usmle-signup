# USMLE Study Tracker - Signup Page

Página de cadastro para o [USMLE Study Tracker](https://drgmb.github.io/usmle-daily-study-tracker/).

## Funcionalidades

- Cadastro com email e senha
- Validação de requisitos de senha em tempo real
- Indicador de força da senha
- Confirmação de senha
- Feedback visual de erros
- Redirecionamento automático após cadastro
- Design responsivo

## Stack

- HTML5
- Tailwind CSS (via CDN)
- JavaScript (ES6+)

## Deploy

Este site é hospedado via GitHub Pages.

**URL:** https://drgmb.github.io/usmle-signup/
